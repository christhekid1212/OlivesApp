# OlivesApp

Τοπική εφαρμογή Windows 10/11 x64 με ελληνικό περιβάλλον για καταχωρήσεις βάρους ελιάς και Bins.

- Σταθερές κατηγορίες: 110, 120, 130, 140, 150, 160, 180, 200.
- Αριθμητικά πεδία, βάρος έως τρία δεκαδικά με κόμμα ή τελεία, ακέραια Bins.
- Αυτόματα σύνολα στη φόρμα και στα Excel.
- Αποθήκευση .xlsx χωρίς εγκατάσταση Excel, με αύξοντα αριθμό και τοπική ημερομηνία/ώρα.
- Επιβεβαίωση αποθήκευσης και ακύρωσης, αναζήτηση μέσω Εξερεύνησης αρχείων.
- Installer με ενσωματωμένο .NET, συντομεύσεις και έλεγχο ενημερώσεων μέσω GitHub Releases.

## Καταχωρήσεις

Η νέα έκδοση αποθηκεύει στα Έγγραφα\OlivesApp\Αρχείο. Ο αριθμός διατηρείται στο .sequence. Κρατήστε αντίγραφο ολόκληρου του φακέλου. Κενά πεδία σημαίνουν μηδέν, αλλά εντελώς κενή καταχώρηση δεν αποθηκεύεται.

Για μετάβαση από την παλιά φορητή έκδοση, χρησιμοποιήστε «Εισαγωγή παλιού αρχείου» με τον παλιό φάκελο Αρχείο πριν από νέες καταχωρήσεις. Τα πρωτότυπα διατηρούνται. Μετά την εισαγωγή χρησιμοποιήστε μόνο τη νέα έκδοση.

## Εγκατάσταση και releases

Δείτε το [RELEASES.md](RELEASES.md) για GitHub Desktop, παραγωγή Setup και δημοσίευση νέων εκδόσεων. Ο updater είναι συνδεδεμένος με το https://github.com/christhekid1212/OlivesApp. Τα αρχεία του πρώτου release βρίσκονται στο dist/Release-1.0.0 και πρέπει να δημοσιευτούν μαζί στο GitHub Releases. Η ενημέρωση μεταξύ δύο online εκδόσεων δεν έχει δοκιμαστεί ακόμη.

## Ανάπτυξη

Απαιτείται .NET SDK 10 σε Windows.

```powershell
dotnet build OlivesApp.csproj -c Release
dotnet bin/Release/net10.0-windows/OlivesApp.dll --self-test
```

Οι έλεγχοι καλύπτουν αριθμητικά πεδία, Excel/σύνολα, αρίθμηση, εισαγωγή παλιών δεδομένων και διευθύνσεις updater. Χρησιμοποιούν προσωρινό φάκελο και γράφουν self-test-result.txt δίπλα στο εκτελέσιμο.
